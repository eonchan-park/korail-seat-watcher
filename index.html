코레일 좌석 알리미

구간·날짜·시간대를 입력하고 조회를 시작하면, GitHub Actions가 5분마다 1시간 동안 좌석을 확인해 이메일로 알려줍니다.

⚙ 최초 1회 설정 (GitHub 저장소 / 토큰)

토큰은 이 브라우저의 localStorage에만 저장되며, GitHub API(api.github.com)로 직접 전송될 뿐 어디에도 커밋되거나 제3의 서버로 전달되지 않습니다. 저장소 Settings → Developer settings → Fine-grained tokens 에서 이 저장소에 대해 Actions: Read and write 권한만 부여해 생성하세요.
이메일 발송용 Gmail 앱 비밀번호는 이 페이지가 아니라 GitHub 저장소의 Settings → Secrets and variables → Actions 에 GMAIL_USER, GMAIL_APP_PASSWORD 이름으로 직접 등록해주세요.
